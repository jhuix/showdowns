# Table of Contents

It's implemented sub-TOC in showdown-toc.js.

## Markdown Syntax

The syntax string is not case sensitive.

```
【TOC】
【目录】
【_TOC_】
【Table Of Contents】
【Table-Of-Contents】

[TOC]
[目录]
[Table Of Contents]
[Table-Of-Contents]

{{TOC}}
{{_TOC_}}
[[TOC]]
[[_TOC_]]

```
